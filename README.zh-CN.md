# Alexandria

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 能把一个宽泛的问题做成有研究、有判断、也好读的 PDF 报告。你只要给出人物、公司、产品、事件、概念、市场或社会现象，它会自己判断该查什么、寻找最新资料、核对证据，再用你提问的语言写成完整报告。

## 怎么完成一份报告

1. **确定研究对象。** Alexandria 会把主题归入人物、组织、事物、事件、概念或系统。类别不同，需要回答的问题也不同。要求已经很清楚时，它会直接开始，不让你先填一长串问题。
2. **带着背景查资料。** 对于现状、价格、政策这类会变化的信息，它会优先寻找最新证据；对于历史和原理，则保留真正有解释力的旧资料。每个重要判断都会记录出处、日期、可信程度和相反证据。
3. **写作并生成 PDF。** Alexandria 会把证据组织成一条讲得通的线，不是把资料简单堆在一起。成稿还要检查信息缺口、过时内容、引用错位和生硬表达，最后排版成 PDF。

你不用自己拆研究任务，也不用在几十个链接里来回整理。拿到的是一份有观点、能核对证据的报告。

## 可以研究什么

人物与创始人、公司与机构、产品与技术、战争与选举、理论与方法、行业与社会趋势，都可以交给 Alexandria。它也能处理混合型题目，比如一家企业在快速变化的市场里到底处在什么位置。

它更适合无法用几句话讲清的问题：事情怎么走到今天，背后由什么推动，谁得利，最近发生了什么，为什么值得关注。

## 成品是什么样

最终报告更像一篇长篇深度报道，不是咨询式幻灯片，也不是百科资料拼接。通常会有封面、目录、按主题安排的章节、明确判断，以及紧跟在相关事实后的引用。篇幅是明确要求：英文必须在 7,500–15,000 词之间，中文必须在 5,000–10,000 个非空白字符之间，成品以约十页或以上为制作目标。题目的复杂程度只决定报告落在区间的哪个位置，不会把深度研究缩成短文。

## 为什么值得试

很多深度研究最后只剩两种结果：一堆链接，或者一篇看起来顺滑却无法核对的文章。Alexandria 想解决的就是这两个问题。给它一个主题，有明确角度就顺手写上。
