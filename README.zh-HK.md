# Alexandria

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 可以把一個寬泛問題整理成有研究、有判斷而且易讀的 PDF 報告。你只需提供人物、公司、產品、事件、概念、市場或社會現象，它會自行判斷要查甚麼、尋找最新資料、核對證據，再按你提問所用的語言寫成完整報告。

## 一份報告怎樣完成

1. **界定研究對象。** Alexandria 會把主題歸入人物、機構、事物、事件、概念或系統。類別不同，要回答的問題也不同。如果要求已經清楚，它會直接開始，不會要你先填一大堆問題。
2. **連同背景一起查證。** 對現況、價格、政策等會變動的資料，它會優先尋找最新證據；至於歷史和運作原理，則保留真正有解釋力的舊資料。每個重要判斷都會記錄出處、日期、可信程度和相反證據。
3. **寫作及製作 PDF。** Alexandria 會把證據組織成一條講得通的線，而不是把資料簡單堆在一起。初稿還會檢查資料缺口、過時內容、引用錯配和生硬文句，最後排版成 PDF。

你不用自己拆分研究工作，也不用在數十條連結之間反覆整理。最後得到的是一份有觀點、證據可追查的報告。

## 可以研究甚麼

人物與創辦人、公司與機構、產品與科技、戰爭與選舉、理論與方法、行業與社會趨勢，都可以交給 Alexandria。它也能處理混合題目，例如一家公司在急速轉變的市場中究竟處於甚麼位置。

它較適合不能用幾句話說清的問題：事情如何發展到今天，背後由甚麼推動，誰會受惠，近期有甚麼變化，以及為何值得留意。

## 完成品是甚麼樣子

最終報告較像一篇長篇深度報道，不是顧問式簡報，也不是把百科資料拼在一起。一般會有封面、目錄、按題目安排的章節、清晰判斷，以及緊貼相關事實的引用。篇幅有明確要求：英文必須維持在 7,500–15,000 詞，中文必須維持在 5,000–10,000 個非空白字符，成品以約十頁或以上為製作目標。題目的複雜程度只決定報告落在區間哪個位置，不會把深度研究縮成短文。

## 為何值得一試

不少深度研究最後只剩兩種結果：一堆連結，或者一篇讀起來流暢、卻無法核對的文章。Alexandria 正是針對這兩個問題。給它一個題目；如果已有明確角度，也一併寫上。
