# Alexandria

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 这个名字来自亚历山大图书馆（古代世界最著名的图书馆之一，曾试图收集来自各地的典籍与知识）。那座图书馆的理想，是把全世界的知识汇聚到同一个地方。我也因此做了 Alexandria：一个什么都能问、什么都能研究的深度研究助手。它会自己判断该查什么、寻找最新资料、核对证据，再用你提问的语言写成完整报告。

## 怎么完成一份报告

1. **确定研究对象。** 人物、组织、事物、事件、概念、系统，或者几种类型混在一起，Alexandria 都能处理。这些分类只是帮助它选择研究方法，不是限制：任何主题都可以研究，没有固定的选题限制。你想问什么都可以。
2. **带着背景查资料。** 对于现状、价格、政策这类会变化的信息，它会优先寻找最新证据；对于历史和原理，则保留真正有解释力的旧资料。每个重要判断都会记录出处、日期、可信程度和相反证据。
3. **写作并生成 PDF。** Alexandria 会把证据组织成一条讲得通的线，不是把资料简单堆在一起。排版前，每份报告都必须通过内置的 Rewild 检查：英文、简体中文和香港繁体中文各用一套规则，先找出 AI 腔，再按需要改写，并逐项核对事实和地区用语；没有通过，就不能进入最终制作。

你不用自己拆研究任务，也不用在几十个链接里来回整理。拿到的是一份有观点、能核对证据的报告。

你发来研究主题后，Alexandria 会先确认收到，再一次问完几个可选的制作问题：报告模板、“撰写”一栏、客户名称，以及是否加入保密字样和标记。它不会等你回复，而是马上开始查资料。你晚一点回答也没关系，最终生成 PDF 前会按你的选择调整；如果一直没有回复，就直接使用默认设置完成报告。

## 可以研究什么

人物与创始人、公司与机构、产品与技术、战争与选举、理论与方法、行业与社会趋势、冷门历史问题，甚至无法归类的题目，都可以交给 Alexandria。这些只是例子，不是一张限定菜单。你可以研究任何对象，也可以从任何角度切入。

它更适合无法用几句话讲清的问题：事情怎么走到今天，背后由什么推动，谁得利，最近发生了什么，为什么值得关注。

## 成品是什么样

你拿到的不是粗糙的文字导出，而是一份专业制作、精心排版、漂亮的 PDF。它有认真设计的封面、目录、按主题安排的章节、明确判断、舒服的版式，以及紧跟在相关事实后的引用。简单说，成品非常漂亮。

PDF 有四套完整设计：

- **A — Executive（默认）：** 象牙白、海军蓝和青绿色，克制、稳重，有咨询公司的专业感。适合商业、战略、金融、政策和组织研究。
- **B — Spectrum：** 白色、钴蓝、紫色、荧光黄绿和黑色，视觉更大胆，也更现代。适合科技、创新、产品、创业公司和未来趋势。
- **C — Atlas：** 白色、森林绿、鼠尾草绿，配合编辑风格图片，像一本精心制作的田野笔记。适合人物、历史、文化、艺术、社会、自然科学和地理主题。
- **D — Horizon：** 黑、白与钴蓝搭配全景图片和悬浮观察卡片，视觉鲜明，信息重点一眼可见。适合基础设施、气候与能源、地缘政治、供应链、韧性、城市和实地市场信号。

你可以直接指定模板，也可以让 Alexandria 根据主题自动选择。“撰写”默认显示 Alexandria；没有客户名称时，整项不会出现；保密功能默认关闭。开启后，封面会加入“严格保密”标记，页脚也会注明“受控文件 · 不得对外传播”。

篇幅是明确要求：英文必须在 7,500–15,000 词之间，中文必须在 5,000–10,000 个非空白字符之间，成品以约十页或以上为制作目标。题目的复杂程度只决定报告落在区间的哪个位置，不会把深度研究缩成短文。

## 为什么值得试

很多深度研究最后只剩两种结果：一堆链接，或者一篇看起来顺滑却无法核对的文章。Alexandria 想解决的就是这两个问题。给它一个主题，有明确角度就顺手写上。
