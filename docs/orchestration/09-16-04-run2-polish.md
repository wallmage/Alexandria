R36.1 `check --fix` rewrites a near-miss link. When a report link is not in the ledger (`binding/link-not-in-ledger`) and exactly one ledger URL or alias has the same normalized path+query and a host that differs only by a `www.` prefix or a public-suffix change (`chinanews.com.cn` vs `chinanews.com`), `--fix` rewrites the report link to that ledger `url` and prints `link rewritten: <old> → <ledger url>` (one line per rewrite, before the Sources regeneration). Rewrite only inside markdown link destinations `](…)` and bare URLs in the body; never inside code fences.
