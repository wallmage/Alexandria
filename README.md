# Alexandria

Alexandria 得名于亚历山大图书馆。那座图书馆曾怀抱汇聚世间一切知识的雄心。我开发这个项目，也抱着同样的愿望：古今中外，宇宙万物，都可以成为深入研究的题目。

**你给 Alexandria 一个主题，它就为这个问题组织一间研究编辑部。面对复杂题目，研究团队可以遍访数百个信息源，逐层评价来源、追查原文、交叉验证，再由总编写成一份讲透来龙去脉、关键判断有据可查的长篇报告。**

从古代历史到当代科技，从人物生平到哲学思想，Alexandria 会为不同题目选择研究框架，安排多轮搜索。广泛搜集的资料还要经过筛选与核实，才能成为报告的依据。团队既寻找支持结论的材料，也主动搜寻可能推翻结论的反证，并检查来源之间是否真正独立：十家网站转述同一篇稿件，只算一个来源；官方主张要与独立证据区分；无法解决的分歧，要写明它会怎样影响结论。

**Alexandria 把研究质量落实到了每一步该做的事上。** 成文前先整理证据与推理，交付前优先抽样回查关键结论引用的原文。你拿到的报告会讲清原理、因果与取舍，保留重要的反对意见，并让你沿着引用核对判断的依据。最后，再配上按主题匹配的版式，交付 PDF 与可编辑的 Markdown 源稿。

[简体中文](README.md) · [English](README.en.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 研究任何主题，没有固定的选题限制，志向是汇聚全世界的知识。交付走 `alx`：init → fetch → find/claims → draft → check --fix → render。成品是专业制作的 PDF，配有紧跟在相关事实后的引用。

## 一套能研究任何主题的框架

研究明朝财政、研究一家芯片公司、研究一种哲学思想，需要追问的问题各不相同。Alexandria 内置六类研究框架，接到主题后选择适合的框架；跨领域题目则组合相关维度。

| 研究对象 | 框架会追问什么 |
|---|---|
| **人物** | 成长背景如何影响选择？哪些决定改变了人生轨迹？成就、争议与时代环境如何相互作用？ |
| **组织** | 如何诞生和演变？内部怎样运作？靠什么竞争？利益与权力如何分配？ |
| **产品、技术与作品** | 核心原理是什么？经历了哪些变化？实际效果如何？与替代方案相比，优势和限制在哪里？ |
| **事件** | 什么条件促成了它？触发点是什么？各方做了什么？后果如何延续至今？ |
| **概念、理论与方法** | 最初要解决什么问题？核心逻辑是什么？如何发展？哪些批评和反例最有力？ |
| **行业、制度与系统** | 规则如何运行？资金、信息和权力怎样流动？谁获益、谁承担代价？变化由什么推动？ |

选定框架后，Alexandria 会列出具体问题，确定先查什么、需要什么证据、查到什么程度才算完成。可能改变结论的问题，要优先查清。

框架用来检查有没有遗漏，文章的章节按题目安排。历史研究可以沿着关键转折展开；技术研究则可以从原理讲到实际限制。

## 像真正的编辑部一样运作

这里的总编和研究员，对应的是分工协作的 AI 智能体。你直接交代任务的那个 AI 是**主智能体**，负责当总编；它为具体任务调度的 AI 助手叫作**子智能体（sub-agent）**，负责当研究员。子智能体接到各自的任务后，分别搜索资料、核对证据，再把调查结果交回总编。

总编先确定报告要回答什么，再拆分任务。例如，同一个题目可以交给几位研究员同时调查：一位追溯历史与原始记录，一位核对当前数据和实际表现，另一位专门寻找争议、失败案例与相反证据。每位研究员有明确的调查范围，总编则掌握整个问题，决定哪些材料能支持结论、哪些地方还要补查。

这就是主智能体与子智能体的分层协作。你只需要提出研究主题，具体分工和结果汇总由 Alexandria 完成。在支持多智能体的环境中，各项调查可以同时进行；无法并行时，也按同一研究计划逐项完成。

搜索从主题名称、别名和专业术语入手，查找论文、档案、财报、公共数据等原始材料。独立报道和当事人经验也要查，后续修订或撤回记录不能漏。必要时使用资料的原始语言检索。

研究员带回的材料包括证据、出处、矛盾、尚未解决的问题和初步分析。总编合并资料、去除重复，判断哪些发现相互支持，哪些需要继续查证，并对最终论证负责。

需要查多少资料，取决于问题有多复杂。关键问题要有证据支持；仍查不清的部分，研究员要记下分歧和资料缺口。完成这些工作后，还要确认继续搜索已不再改变判断，才结束调查。Alexandria 没有固定的来源数量要求。

## 每个来源都要评价，每个关键判断都要查证

### 从来源背景和证据类型判断可信度

Alexandria 会辨别资料与研究对象的关系，区分五类来源背景：

| 来源类别 | 核实时关注什么 |
|---|---|
| **一手且独立** | 是否直接掌握证据，研究或记录方法是否可靠？ |
| **一手但有利益关系** | 官方文件、厂商数据、当事人陈述究竟能证明什么？哪些只是自身主张？ |
| **二手且独立** | 是否做过独立调查？解释能否追溯到原始证据？ |
| **二手且依赖其他报道** | 是否只是转述同一份材料？有没有新增核实？ |
| **匿名、不可核实或转载** | 原始出处在哪里？能否验证？是否只能作为继续调查的线索？ |

同时，它会区分财务披露、同行评审研究、预印本、官方文档、独立测试、新闻采访、观点与营销材料，再对具体判断标注高、中、低可信度。

权威性与独立性需要分别判断。财报能支持披露的营收数字，不能直接证明产品更好；企业公告能证明公司公布了某项计划，不能证明计划一定可行。即使出自知名媒体，一篇转述稿也不能凭空增加一份独立证据。

### 多篇报道，可能只有一个出处

十家网站转载同一篇稿件，背后仍然只有一个来源。来自同一家机构的多个页面，或者使用同一数据集的多项研究，也不能简单算成多方印证。

Alexandria 会合并这些共同来源。关键判断要获得充分交叉验证，需要至少两个独立来源体系相互支持，其中至少一个独立于研究对象。证据不足时，会降低结论的可信度，并说明限制。

遇到冲突，先核对日期、定义、样本与利益关系，再寻找原始记录和后续更正。能解决的分歧，要说明采信哪一方、为什么；解决不了的，保留分歧及其对结论的影响。

### 主动寻找能推翻自己的证据

在确认核心判断前，Alexandria 要提出最有力的另一种解释，并搜索能区分两种解释的证据。失败案例、负面结果、边界条件与当事人的反对意见，都属于研究任务。

例如，研究一项技术是否领先，除了找支持其表现的测试，还要检查测试条件、失败场景和替代方案。最终判断必须经受这些反证的检验。

### 先建证据记录，再开始成文

重要说法都有对应的证据记录：原文摘录或位置、来源、日期、可信程度、相关矛盾，以及从证据到判断的推理过程。事实、当事人主张、估算和分析分别记录。

写作之前，先核对引语、清理重复来源、处理争议并标明资料缺口。交付前，再对关键结论优先抽样回查在线原文，确认记录中的证据确实出自所引页面。会变化的信息还要检查时效。

## 历史、地缘政治与人物传记，各有各的写法

Alexandria 内置六种写作模式，中文和英文都可以使用。总编根据题目选定主要文体，再决定从哪里讲起、哪些材料值得展开，以及怎样把证据写成读者能理解的解释。

你也可以用熟悉的作家或职业写手来描述期待的写法。比如，中文历史研究可以提出“借鉴黄仁宇从制度与时代条件理解人物选择的分析方法”；英文人物传记可以提出“借鉴沃尔特·艾萨克森以关键选择组织人物经历的方法”。这些是写作方法的参照，具体文章由智能体依据查证过的材料完成。

六种模式落实到选题上，会有这样的区别：

| 模式 | 具体题材 | 文章怎样展开 |
|---|---|---|
| **历史型** | 中文历史，例如明朝财政 | 从白银这个具体问题进入，追问财政制度、贸易和地方治理如何相互影响，再把人物的选择放回当时的条件中理解。既看关键转折，也区分当时人的认识与后世的解释。 |
| **调查型** | 地缘政治、冲突与争议 | 采用战地记者核实报道的工作方法，分别交代各方说了什么、记录证明了什么、独立资料证实了什么。顺着事件与利益关系解释局势，保留无法核实的部分。现场细节必须有来源。 |
| **叙事型** | 英文人物传记、创始人研究 | 采用纪实传记的组织方式，围绕改变人生轨迹的决定展开：当时面对什么处境，有哪些选择，行动带来什么后果。用有记录的经历、言论与转折呈现人物，再联系更大的时代背景。 |
| **分析型** | 中文或英文商业、科技产业研究，例如 NVIDIA | 采用财经与科技深度报道的写法，先提出核心判断，再拆解硬件、软件生态和客户依赖。比较优势、代价与替代方案，解释哪些因素可能削弱当前地位，让读者看清判断成立的条件。 |
| **解释型** | 科技原理、哲学思想，例如存在主义 | 采用善于讲解的科普作者的写法，从具体问题进入，逐步说明概念和逻辑。术语第一次出现就解释，再用分歧、反例和适用边界检验读者刚刚建立的理解。 |
| **评论型** | 产品、作品与思想的评价 | 采用专业评论者的写法，先把对象讲准确，再亮出评价标准，比较可信的替代方案。结论要能回答“为什么这样评价”，也交代合理的不同意见和可能改变评价的证据。 |

这些区别会影响整篇文章。历史研究需要交代时代条件，人物传记要给关键经历足够的篇幅，科技分析则要把原理和实际限制解释清楚。每节可以根据材料选择不同的展开方式，全文保持一种主要文体。

中文和英文各有独立的编辑规则。简体中文使用自然的中文表达，港式繁体按香港读者的用词和书面语习惯处理；英文则检查具体措辞、句子节奏与论证衔接。数字、引语和必要的限定条件，在任何文体中都必须忠于证据。

## 交付经过排版与检查的报告

内置 **11 套视觉模板**，覆盖稳重的商业报告、人文历史、科技、生态等主题。默认交付两份内容相同的 PDF：一份使用 Executive，另一份根据主题自动匹配风格。你也可以直接指定一种模板。

成品包含封面、目录、分章正文和可点击引用。生成后会重新打开 PDF，检查文字、链接、字体、分页与溢出，并查看页面图像，修正裁切、空白页等问题。需要查看设计选项时，可读[模板说明](references/pdf-templates.md)。

你会拿到：

- **完整长篇报告**：中文 5,000–10,000 个非空白字符；英文 7,500–15,000 词。通过补充证据和深入分析达到篇幅要求。
- **经过检查的 PDF**：以约十页或以上为制作目标，实际页数随语言与版式变化。
- **Markdown 源稿**：方便检索、摘录、修改和继续使用。
- **紧随相关论断的来源引用**：方便你核对证据、继续阅读原始资料。

## 为什么跑一次可能要半小时？

一次完整研究包括这些步骤：

**选题拆解 → 分工搜索 → 来源评价 → 交叉验证与反证 → 证据汇总 → 总编成文 → PDF 制作与目检**

这些步骤还可能需要回头重做。比如，两个来源相互矛盾，要继续查原始记录；稿子写完才发现关键论据不足，就得补研究。修改文字如果影响了结论，也要重新核对。

复杂主题可能需要半小时或更久，实际耗时取决于题目、资料是否容易找到、模型和运行环境。

## 开始你的第一份研究

把仓库链接或 ZIP 交给支持技能、联网研究和本地执行的智能体，说：

> 帮我安装这个 skill。

智能体会按 [INSTALL.md](INSTALL.md) 完成环境安装和 PDF 验证。装好后，直接给它一个主题：

> 用 Alexandria 深度研究：为什么明朝财政长期困于白银？从制度、贸易与地方治理解释，写成中文报告。

> 用 Alexandria 研究 NVIDIA 的竞争优势。拆解硬件、软件生态与客户依赖，并检验最可能削弱它的因素。

> 用 Alexandria 解释存在主义。讲清它的问题意识、主要分歧，以及它如何影响普通人的选择。

有想了解的角度、读者或时间范围，就一并告诉它。只有一个主题，也可以开始。
