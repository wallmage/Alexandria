# Alexandria

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 這個名字來自亞歷山大圖書館。那座圖書館的理想，是把全世界的知識匯聚在同一個地方。我亦因此製作了 Alexandria：一個甚麼都可以問、甚麼都可以研究的深度研究助手。它會自行判斷要查甚麼、尋找最新資料、核對證據，再按你提問所用的語言寫成完整報告。

## 一份報告怎樣完成

1. **界定研究對象。** 人物、機構、事物、事件、概念、系統，或幾種類型混合在一起，Alexandria 都能處理。這些分類只用來協助它選擇研究方法，並非限制：任何題目都可以研究，沒有固定的選題限制。你想問甚麼都可以。
2. **連同背景一起查證。** 對現況、價格、政策等會變動的資料，它會優先尋找最新證據；至於歷史和運作原理，則保留真正有解釋力的舊資料。每個重要判斷都會記錄出處、日期、可信程度和相反證據。
3. **寫作及製作 PDF。** Alexandria 會把證據組織成一條講得通的線；排版前，報告必須先通過相應語言的 Rewild 檢查，再接受一次內容審查，逐項核對結論、資料來源是否獨立、相反證據、推理過程、分析深度和實際價值。

你不用自己拆分研究工作，也不用在數十條連結之間反覆整理。最後得到的是一份有觀點、證據可追查的報告。

你交出研究題目後，Alexandria 會先確認收到，再一次問齊幾項可選的製作設定：報告模板、「撰寫」一欄、客戶名稱，以及是否加入保密字句和標記。它不會等你回覆，而是立即開始查資料。你遲一點回答也沒問題；如果沒有選模板，Alexandria 會用同一份內容製作兩份 PDF：一份採用預設的 Executive，另一份按研究題目自動選擇設計。

## 可以研究甚麼

人物與創辦人、公司與機構、產品與科技、戰爭與選舉、理論與方法、行業與社會趨勢、冷門歷史問題，甚至難以歸類的題目，都可以交給 Alexandria。這些只是例子，不是一張限定選單。你可以研究任何對象，也可以從任何角度切入。

它較適合不能用幾句話說清的問題：事情如何發展到今天，背後由甚麼推動，誰會受惠，近期有甚麼變化，以及為何值得留意。

## 完成品是甚麼樣子

你收到的不是粗糙的文字匯出，而是一份經過專業製作和精心排版的 PDF。它有認真設計的封面、目錄、按題目安排的章節、清晰判斷、舒適的版面，以及緊貼相關事實的引用。

十一套模板共用同一套製作系統：字級層次、表格與引文樣式、正文頁結構全部一致，因為一份四十頁的文件讀不讀得下去，靠的正是這些。各套之間的分別在封面處理、配色和字體，而讀者第一眼記住的，大致也就是這些。一份私募備忘錄和一份流域生態研究不應該長得一樣，實際上亦不一樣。

| | 模板 | 視覺 | 適合 |
|---|---|---|---|
| A | **Executive**（預設） | 象牙白、海軍藍、青綠；克制穩重，專業顧問公司的感覺 | 商業、策略、金融、政策、機構研究 |
| B | **Spectrum** | 白、鈷藍、紫、螢光黃綠；大膽而現代的訊息面板 | 數碼產品、媒體、消費科技、初創企業、未來趨勢 |
| C | **Atlas** | 白、森林綠、鼠尾草綠；編輯風格圖片，像田野筆記 | 人物、歷史、文化、藝術、社會、自然科學、地理 |
| D | **Horizon** | 黑、白、鈷藍；全景圖片與懸浮觀察卡片，重點一眼可見 | 基建、氣候與能源、地緣政治、供應鏈、城市 |
| E | **Maison** | 暖象牙白、醒目襯線字體、充足留白；高級雜誌感 | 奢侈品、酒店、零售、旅遊、地產、餐飲、消費品牌 |
| F | **Blueprint** | 黑、白、技術藍；網格、基準線、節點與流程圖 | 營運模式、機構設計、工程、管治、執行、企業轉型 |
| G | **Terrain** | 森林綠、米白；航拍圖、等高線與地圖標記 | 生態、保育、農業、水資源、土地運用、天然資源 |
| H | **Orbit** | 電光鈷藍、黑白；高精度幾何圖形與科學影像 | AI、半導體、機械人、先進科學、深科技 |
| I | **Sunbeam** | 墨黑、橙色、向日葵黃；醒目襯線字體與圓形圖案 | 創業、教育、青年發展、公眾參與、社會影響、社區項目 |
| J | **Current** | 暖白底色、流動橙色曲線、親切無襯線字體與路線圖形 | 出行、顧客旅程、創新項目、服務營運、未來工作、機構變革 |
| K | **Apricot** | 暖象牙白、杏橙色；人文攝影與舒展的襯線版面 | 職場文化、照顧、公共健康、學習、人才策略、社區福祉 |

你主動選模板時，Alexandria 會按你的選擇製作一份 PDF；如果沒有選，就會製作 Executive 和一份按題目自動配對的版本——配對規則是確定的，同一個題目永遠得到同一套模板。第二份沿用已完成的正文、資料來源和引文，不會重新研究或寫作，只多一次本機排版。「撰寫」預設顯示 Alexandria；沒有提供客戶名稱時，該欄不會顯示；保密功能預設關閉。開啟後，封面會加入「嚴格保密」標記，頁尾亦會註明「受控文件 · 不得對外傳閱」。

篇幅有明確要求：英文必須維持在 7,500–15,000 詞，中文必須維持在 5,000–10,000 個非空白字元，成品以約十頁或以上為製作目標。題目的複雜程度只決定報告落在區間哪個位置，不會把深度研究縮成短文。

## 為何值得一試

不少深度研究最後只剩兩種結果：一堆連結，或者一篇讀起來流暢、卻無法核對的文章。Alexandria 正是針對這兩個問題。給它一個題目；如果已有明確角度，也一併寫上。
