# Alexandria

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文（香港）](README.zh-HK.md)

Alexandria 這個名字來自亞歷山大圖書館（古代世界最著名的圖書館之一，曾嘗試收藏來自各地的典籍與知識）。那座圖書館的理想，是把全世界的知識匯聚在同一個地方。我亦因此製作了 Alexandria：一個甚麼都可以問、甚麼都可以研究的深度研究助手。它會自行判斷要查甚麼、尋找最新資料、核對證據，再按你提問所用的語言寫成完整報告。

## 一份報告怎樣完成

1. **界定研究對象。** 人物、機構、事物、事件、概念、系統，或幾種類型混合在一起，Alexandria 都能處理。這些分類只用來協助它選擇研究方法，並非限制：任何題目都可以研究，沒有固定的選題限制。你想問甚麼都可以。如果要求已經清楚，它會直接開始，不會要你先填一大堆問題。
2. **連同背景一起查證。** 對現況、價格、政策等會變動的資料，它會優先尋找最新證據；至於歷史和運作原理，則保留真正有解釋力的舊資料。每個重要判斷都會記錄出處、日期、可信程度和相反證據。
3. **寫作及製作 PDF。** Alexandria 會把證據組織成一條講得通的線，而不是把資料簡單堆在一起。初稿還會檢查資料缺口、過時內容、引用錯配和生硬文句，最後排版成 PDF。

你不用自己拆分研究工作，也不用在數十條連結之間反覆整理。最後得到的是一份有觀點、證據可追查的報告。

## 可以研究甚麼

人物與創辦人、公司與機構、產品與科技、戰爭與選舉、理論與方法、行業與社會趨勢、冷門歷史問題，甚至難以歸類的題目，都可以交給 Alexandria。這些只是例子，不是一張限定選單。你可以研究任何對象，也可以從任何角度切入。

它較適合不能用幾句話說清的問題：事情如何發展到今天，背後由甚麼推動，誰會受惠，近期有甚麼變化，以及為何值得留意。

## 完成品是甚麼樣子

你收到的不是粗糙的文字匯出，而是一份專業製作、精心排版、漂亮的 PDF。它有認真設計的封面、目錄、按題目安排的章節、清晰判斷、舒適的版面，以及緊貼相關事實的引用。簡單來說，成品真的很漂亮。

篇幅有明確要求：英文必須維持在 7,500–15,000 詞，中文必須維持在 5,000–10,000 個非空白字符，成品以約十頁或以上為製作目標。題目的複雜程度只決定報告落在區間哪個位置，不會把深度研究縮成短文。

## 為何值得一試

不少深度研究最後只剩兩種結果：一堆連結，或者一篇讀起來流暢、卻無法核對的文章。Alexandria 正是針對這兩個問題。給它一個題目；如果已有明確角度，也一併寫上。
