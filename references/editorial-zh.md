# 中文证据安全编辑

目标是写得清楚、自然、可信，不是刻意制造"人味"。

本文件与 `editorial-en.md` 是同一套标准的两个语种版本，要求等同。中文的 AI 腔与英文不同，所以下面的可计量上限按中文自身的套话来设，不是英文规则的翻译。

## 基本要求

- 先说结论，再解释原因。
- 每一节都要完成一项明确任务：回答读者的问题，讲清证据或机制，检验重要限制，再说明这件事为什么重要。
- 用具体的人、事、数字和动作，少用空泛的大词。
- 删除铺垫过长、同义反复和模板化过渡。
- 一段只推进一个重点。
- 专业术语、产品名称和内部叫法第一次出现时就解释清楚，之后保持叫法一致；不解释读者理解或决策的名字，直接删掉。
- 标题要传达信息，不要只写"背景""意义"这类空标题。
- 保留必要的限定、分歧和不确定性，但不要把不确定写成确定。
- 不新增证据记录里没有的事实、例子、引语或细节。
- 需要时加入真正有解释力的案例、对比或演算过程，不要为了生动硬塞故事。
- 数字值得写进报告，就要把数值本身写出来并给出处。不要只告诉读者"存在一个公开区间"却不写这个区间是多少。
- 凡是涉及平台差异、数字、法律、政策等外部可核查的说法，该段就要有引用。只在文末列参考文献，不能让正文变得可追溯。
- 同一个判断在执行摘要里说一次，在证据汇总的地方再说一次即可。读者画像、检查清单、试点建议如果考察的是同一批维度，合并成一处。
- 篇幅要求不变。删掉重复内容后，要用更扎实的证据、机制、反证、对比或影响补足深度，不能把长报告改成短文。

## 可计量上限

按成稿统计，不抽样；标题、表格、引用块和"参考资料"一节不计入。中文报告以非空白字符计长度（全文 5,000–10,000 非空白字符），下列密度也按非空白字符折算。每一项都是上限，不是指标，远低于上限是好结果。

| 套路 | 上限 |
|---|---|
| 一句里并列五项及以上（顿号或逗号串联） | 每 1,000 非空白字符 4 次 |
| 「不是……而是……」对举句式 | 全文 2 次 |
| 分号对举（「对 A 来说是……；对 B 来说是……」） | 全文 2 次 |
| 段末评价性收尾（见下列四种模板，合计） | 不超过正文段落的 20% |
| 「，这意味着」「，这使得」「，从而」「，也就是说」式追加判断 | 每 1,000 非空白字符 2 次 |
| 破折号 | 每 1,000 非空白字符 2 次 |
| 四字格成语／对仗短语（「日新月异」「方兴未艾」「举足轻重」「不容忽视」等） | 每 1,000 非空白字符 2 次 |
| 排比句（三个及以上同构分句连用） | 全文 2 次 |
| 「不仅……而且」「不但……还」「一方面……另一方面」合计 | 每 1,000 非空白字符 2 次 |
| 自指：「本报告」「本文」「以上分析」 | 全文 2 次 |
| 叠加限定（一个说法上套两层不确定：「可能在一定程度上或许」） | 0 |

上限与准确性冲突时，准确性优先。该保留的限定、引用、对比一律保留，改删别处的装饰性用法。

## 必须删干净的中文套话

这些不设上限，出现即删：

- **口语化填充**：「其实」「说白了」「众所周知」「毋庸置疑」「显而易见」「值得注意的是」「不难发现」。前四个还预设了读者已经同意，属于替读者下结论。
- **空洞总起总结句**：「总的来说」「综上所述」「由此可见」「在……的今天」「站在……的十字路口」。段落要靠内容收尾，不靠连接词宣布收尾。
- **公文式起句**：「随着……的不断深入」「随着……的快速发展」「近年来，随着……」。这是中文 LLM 最容易复现的开头，几乎总能改成一个具体的时间点加一件具体的事。
- **抽象后缀堆叠**：「提升了整体的可用性与可扩展性」这类由「性」「化」「度」堆出来的句子。改成谁做了什么、结果怎样。
- **万能大词**：「赋能」「抓手」「生态闭环」「打造新格局」「持续深化」「全面提升」。这些词在报告里不承担信息量。
- **虚指代**：「这一现象」「这种情况」「上述问题」，当读者要往回翻两段才知道指什么的时候，直接把名词写出来。

## 段末的四种模板

给它们起名，便于复查时逐条搜：

1. **逗号对举**：「这说明该走得更保守，而不是更激进。」
2. **冒号下判断**：「它改变的是评估的着力点：眼下是否合用，比上季度的跑分更要紧。」
3. **「，这意味着」追加判断**：「席位按月计费，这意味着席位单价并不等于真实成本。」
4. **分号对举**：「对招聘经理，这个区别是决定性的；对架构师，它只是噪音。」

单看每一句都成立，毛病出在重复。当每两段就有一段落在同一个句式上，读者读到的不再是判断，而是节拍。

## 让段落自然结束

正文里至少一半的段落，应该停在最后一个事实、数字、出处或机制说明上，后面不再补一句评价。做完事的段落不需要再挂一个判断；把没有收束的事实交给下一段，读起来是笃定，不是心虚。

评价性收尾留给章节末尾，以及全文中真正以"影响"为重点的两三处。不要为了显得有分量而硬加金句。

## 限定语的位置

报告需要限定语。它读起来是严谨还是退缩，取决于位置。

- **限定前置**。把条件放在句首，让整段落在实质内容上：「在厂商自测的基准里，延迟下降了三分之一」，而不是「延迟下降了三分之一，不过这是厂商自测的基准，未必普遍适用」。两句的不确定性完全相同，只有前一句让读者拿到了一个事实。
- **一个说法只用一层限定**，并且选真正对应证据弱点的那一个。叠两层不是更谨慎，读者读到的是作者没有立场。
- **不确定性来自"谁说的"时，用归属代替限定**：写「财报披露流失率为 12%」，不写「流失率可能在 12% 左右」。
- **核心判断只强调两次**：执行摘要一次，证据汇总处一次。每节都把主论点的关键词再念一遍，读起来像是不放心读者有没有看懂，也挤掉了这一节自己该讲的东西。
- **别把报告写进报告**。要写研究对象，不要写这份文件本身。「本报告认为采用率在 2024 年停滞」是在讲写作，「采用率在 2024 年停滞」才是在讲世界。

## 简体与港式繁体的语域差异

两者分别处理，不是字形转换。人名、产品名、代码和文献标题一律以准确为先。

**简体中文**要额外提防大陆官样文体与新华体：「高质量发展」「深度赋能」「打造……新生态」「实现从……到……的转变」「为……注入新动能」。这类词组在中文语料里密度极高，模型极易复现，而它们在研究报告里不提供任何可核查的信息。数字用阿拉伯数字，术语跟随大陆通行译名（如"人工智能""芯片""软件"）。

**港式繁体**要写成香港读者日常读到的中文，参照本地财经与专业报告的语域：用「機構」「數碼」「初創企業」「管治」「匯出」「本機」「甚麼」这类本地词，不用「打造」「賦能」「抓手」「落地」等大陆管理术语，也不用「軟體」「網路」「品質」等台湾用词。港式繁体另有一类要节制的公文腔：「就……而言」「作出檢討」「進行分析」「予以」「有關方面」。「進行 + 双音节动词」能改回单个动词就改（「進行分析」→「分析」）。中英夹用在香港专业写作里是常态，专有名词、职衔和技术术语保留英文原文比硬译更自然，但整句中英混杂要避免。

上表的所有上限对两种语域同等适用。

## 校对流程

改完之后分四遍读：一遍看论证，一遍看阅读价值，一遍看证据一致性，一遍出声读节奏。上面那些上限主要在读节奏这一遍暴露；收工前再搜一次四种段末模板和破折号。

凡是改动可能影响原意，都要回到证据记录核对数字、日期、姓名、引语、单位和引用位置。
